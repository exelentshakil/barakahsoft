# plumbers-electricians — design reference

**Tahoe Ridge Electric** — Lake Tahoe / Truckee, CA
`tahoeridgeelectric.com`

Reused from the existing `home-services-trades/electricians/` library, where it was rated the
strongest single find in that set. A stunning real aerial photo of the lake carries the hero
instead of the usual stock van-and-technician shot. Forest-green and burnt-orange palette with
an editorial serif/monospace type pairing that reads hand-built rather than templated. Real
snow-covered cabin and chalet project photography, and a specific named testimonial (Karen
Barchas) with genuine job detail. Proof that a trade site can be beautiful without losing the
service-grid clarity the trade needs.
